# Typeface Registry — faces in use across this portfolio

> Same discipline as the Design Registry, for type: track what each project shipped,
> and before committing to any face, check for reuse, look-alikes, and known
> AI-darling faces. A callout is not a veto — the human decides.

## Known AI-darling faces (community-sourced starting set)

a ban: Inter-as-default · Space Grotesk · Instrument Serif · Fraunces ·
Playfair-Display-as-instant-luxury · generic mono families as page voice. Grow and
prune from your own catches.

## The check (before proposing or committing to any face)

1. **Exact reuse** — face already registered to another project? Call it out.
2. **Look-alike** — shares distinctive glyph DNA with a registered face (the same
   single-story a, the same ball terminals, the same superellipse rounds)? Call it
   out with the shared trait.
3. **AI-darling** — on the list above? Call it out and name a stronger alternative in
   the same register.
4. **Role fit** — a face proposed outside its register (a display face asked to set
   body, a mono asked to be a voice instead of a narrow diegetic role) gets flagged.

Update rows whenever a project's fonts change or a new design project starts.
