> human decides.

## The check (run before proposing any visual direction or showing any comp)

1. **World first** — is there a named world the palette/type/motifs derive from? No
   world → stop and get one (`direction` mode).
2. **Exact reuse** — palette, hero motif, or signature move already registered under
   another project? Call it out.
3. **Family resemblance** — shares distinctive DNA with a registered row (another
   paper/ink/single-accent scheme, another map-texture world)? Call it out with the
   specific shared trait.
4. **AI-tell** — matches the list above? Call it out.
5. **Fonts** — run `Typeface-Registry.md`'s check.
6. **Own borrowings** — a reference steal that is a registered signature move of
   another project in THIS portfolio is exact reuse too ("repetition versus
   iteration").
7. **Model-tells** — check the list below against every comp before showing it.

## Model-tells (this model's own recurring moves)

Moves this model reaches for regardless of world. A move earns a row when it appears
in 2+ outputs across different worlds. Grow from every critique.

**How to use this list — replace, never delete:** tells are common because they work;
design by avoidance leaves holes where the power was. The list is LINT, not a brief:
commit to the strongest positive move first, then swap any flagged tell for a
stronger move from a real reference. A bare deletion fails the check too.
